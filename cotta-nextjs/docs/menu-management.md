# ניהול מנות ותוכן האתר

כתובת הממשק: `/admin/menu`. כניסה עם אותם פרטי הצוות של מערכת ההזמנות (`ORDERS_USERNAME`, `ORDERS_PASSWORD`). אפשר להגיע אליו גם דרך ניהול תפריט בממשק המסעדה או דרך הקישור בתחתית האתר.

אפשר להוסיף מנה, לערוך שם, כותרת משנה, תיאור, מחיר בשקלים, קטגוריה, תגיות, סדר תצוגה וזמינות. ניתן להעלות תמונה מהמחשב או מהטלפון, או לבחור תמונה קיימת. התמונות מוקטנות לפני ההעלאה, נבדקות ומומרות ל־JPEG בשרת, ונשמרות ב־MongoDB GridFS. אין תלות בכתיבה לדיסק של Vercel.

האתר, דפי המנות ותפריט ההזמנות קוראים מאותו קטלוג MongoDB. דף פתוח מציג את המידע שטען; רענון מציג את השינויים האחרונים. בעת ביצוע הזמנה המחיר נבדק מחדש בשרת. הזמנות קיימות שומרות את שמות המנות והמחירים המקוריים שלהן.

מחיקה מסירה את המנה מהקטלוג הציבורי ומדף המנה, ושומרת סימון מחיקה במסד כדי שלא תיווצר מחדש בעת אתחול. בזמן הפעלה ראשונה, פרטי התפריט הישן מועתקים לשדות החדשים בלי לשנות את זמינות המנות או את סרטוניהן. עריכות שנשמרו אינן נדרסות בהפעלה מחדש.

בדיקות נתונים: `npm run test:orders`. בדיקת ממשק מלאה: `npm run test:catalog` (דורשת את Playwright המקומי תחת `.qa` ו־Chrome). הבדיקות משתמשות במסד זמני ומבודד.
